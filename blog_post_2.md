### How to Use TTS for Maximum Learning

**1. Create Study Playlists**
Convert all your course materials into audio. Listen in order while reviewing notes.

**2. Active Listening**
Don't just passively listen. Take notes, pause to reflect, replay difficult sections.

**3. Combine with Visual Learning**
Read while listening. This "dual coding" improves memory by 65%.

**4. Adjust Playback Speed**
Most tools let you speed up narration. 1.25x or 1.5x speed saves time without losing comprehension.

**5. Create Flashcards from Audio**
Listen to key concepts, then create flashcards. Reinforces learning.

### Best Practices for Student TTS

✅ Use for review, not primary learning
✅ Combine with note-taking
✅ Try 1.25-1.5x playback speed
✅ Create themed playlists by subject
✅ Use multi-voice for textbooks with dialogue
✅ Download for offline access
